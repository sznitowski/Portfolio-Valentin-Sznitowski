# Portfolio Comercial — Valentín Sznitowski

Portfolio profesional orientado a la captación de clientes comerciales (comercios, talleres, pymes y profesionales independientes) y a la presentación de soluciones digitales y productos web reales.

## Stack Tecnológico

- **Framework:** Next.js 15 (App Router)
- **Biblioteca:** React 19
- **Lenguaje:** TypeScript (strict mode)
- **Estilos:** Tailwind CSS v4 (design tokens semánticos en CSS variables)
- **Iconografía:** Lucide React

## Proyecto Principal Destacado

- **Custom Commerce:** Plataforma comercial con catálogo dinámico, personalización de medidas y cotización a WhatsApp.  
  Demo pública: [https://custom-commerce.netlify.app](https://custom-commerce.netlify.app)

## Comandos de Desarrollo

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo local (http://localhost:3000)
npm run dev

# Generar compilación de producción
npm run build

# Ejecutar verificación de tipos
npm run typecheck

# Ejecutar linter
npm run lint
```
